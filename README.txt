# AI Image Detection

A system that analyzes a digital image and determines whether it was taken by a real camera or generated by an AI model such as Midjourney, Stable Diffusion, or DALL-E.

The system uses four analysis modules:
- PRNU — analyzes camera sensor noise patterns
- ELA — analyzes JPEG compression error levels
- FREQ — analyzes frequency domain signatures (FFT, DCT)
- Metadata — checks EXIF data for AI tool signatures

Each module runs independently and their scores are combined using a weighted average to produce a final verdict.

 Project Structure

```
imageMetadata/
├── CNN/
│   ├── feature_extract/
│   │   ├── inference.py          # loads models and runs all 4 modules
│   │   ├── score_fusion.py       # combines scores into final verdict
│   │   ├── frequency_extractor.py
│   │   └── PRNU_and_ELA_preparing.py
│   ├── noise_residuals/
│   │   ├── noise_residual_extraction.py
│   │   └── ELA_extraction.py
│   ├── saved_modules/            # trained model .pth files
│   └── cnn_training.py           # training pipeline
├── metadata_extract/
│   └── metadata_scorer.py
├── web/
│   └── app.py                    # Flask API server
└── test_pipeline.py              # end-to-end test script
```

---

 Setup

**1. Install Python dependencies**
```bash
pip install -r requirements.txt
```

**2. Install frontend dependencies**
```bash
cd web/frontend
npm install
```

---

 Running the System

**Start the Flask backend** (from project root):
```bash
cd web
python app.py
```

**Start the React frontend** (in a separate terminal):
```bash
cd web/frontend
npm run dev
```

Then open `http://localhost:5173` in your browser.

---

 Testing a Single Image

From the project root:
```bash
python test_pipeline.py path/to/image.jpg
python test_pipeline.py path/to/image.jpg face
```

The second argument is optional. Use `face` for portraits and deepfake detection, leave it out for general images.

---

 Training

To retrain the models, update the paths in `CNN/cnn_training.py` and run:
```bash
python -m CNN.cnn_training --mode prnu --max_samples 10000
python -m CNN.cnn_training --mode ela  --max_samples 10000
python -m CNN.cnn_training --mode freq --max_samples 10000
```

Run once for general images, then update the paths and run again for face images.
